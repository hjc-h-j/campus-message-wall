# 校园信息墙（校园留言墙）
 毕业设计项目：校园轻量化留言交流系统
 ## 项目简介
 本系统面向校园师生，打造轻量化的公开留言交流平台。用户可发布带标签、图片的留言，支持多层评论回复、点赞、消息通知；管理员可对留言内容进行管理。
 对比微信班级群、公众号表白墙，本系统能够实现内容沉淀，方便持续浏览检索，弥补传统渠道消息容易刷屏、投稿延迟的不足。
 ## 技术栈
 - 前端：Vue3 + Element Plus
 - 后端：Node.js + Express
 - 数据库：MySQL
 ## 主要功能
 用户注册、登录鉴权
 留言发布，支持正文、标签、图片上传
 评论、多层嵌套回复
 点赞、取消点赞
 消息通知
 留言内容管理
 ## 项目启动
 1. 导入MySQL数据库脚本
 2. 进入后端目录，安装依赖：`npm install`
 3. 启动后端服务
 4. 进入前端目录，安装依赖：`npm install`
 5. 启动前端：`npm run dev`
